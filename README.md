# Tic Tac Toe Game

A simple two-player Tic Tac Toe game built with HTML, CSS and JavaScript. Players take turns as X and O until someone wins or the game ends in a draw.

## Features

- Two players take turns (X and O)
- Detects a win (rows, columns, diagonals)
- Detects a draw
- Highlights the current player
- Restart button to play again

## Tech Stack

- HTML: game board structure
- CSS: styling and layout
- JavaScript: game logic

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/shagunnichant93/tic-tac-toe.git
```
2. Open the folder:
```bash
   cd tic-tac-toe
```
3. Open `index.html` in your browser (or use the Live Server extension in VS Code).

## How to Play

1. Player X starts first.
2. Click an empty square to place your mark.
3. The first player to get 3 in a row (horizontal, vertical or diagonal) wins.
4. If all 9 squares are filled and nobody has won, it's a draw.
5. Click **Restart** to start a new game.
